IF YOU DO NOT HAVE HOMEBREW, YTDLP AND FFMPEG INSTALLED YET DO THIS BEFORE INSTALL:

1. Go to homebrew website and install homebrew

2. Run this in terminal to download yt-dlp (you might need to enter user password:
	
	brew install yt-dlp

3. Run this command in terminal to install ffmpeg:

	brew install ffmpeg

YOU CAN DELETE THIS FOLDER ONCE INSTALLATION IS DONE! A NEW README.TXT WILL BE IN THE 
INSTALLED FOLDER WITH INFORMATION ON HOW TO USE THE TOOL.
